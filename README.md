\# MidSideControl v2 



Plugin VST3 de procesamiento Mid/Side para mezcla y masterización.



\##  Documentación y Manual de Usuario

Puedes consultar el manual de uso completo en formato PDF:

\*  \[Descargar Manual de Usuario (PDF)](./docs/MidSideControl\_User\_Manual.pdf)



\##  Instalación

1\. Ve a la sección de \*\*Releases\*\* a la derecha.

2\. Descarga el archivo `.vst3` según tu sistema operativo.

3\. Copia el archivo en tu carpeta de VST3.
